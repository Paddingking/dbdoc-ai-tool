# DBDoc AI — 开发执行计划

> 创建日期: 2026-06-30
> 技术栈: Electron + React + Vite + Spring Boot 2.7 + Java 8
> 复用基础: PPTForge 项目框架 (~90% 复用)

---

## 一、项目目标

**MVP 交付物 (4周):**
连接 MySQL/PostgreSQL 数据库 → 生成带交互式 ER 图的文档门户 → AI 自动推断字段说明 → 导出 HTML

**商业定位:**
本地优先、私有化部署的数据库文档自动生成工具

## 四、技术架构

```
dbdoc-ai/
├── frontend/                 ← Electron + React + Vite
│   ├── src/
│   │   ├── components/       ← Toast, ErrorState, EmptyState, LoadingSkeleton
│   │   ├── pages/            ← DataSourcePage, TableSelectPage, DocPortalPage, SettingsPage
│   │   ├── services/         ← api.ts (REST客户端)
│   │   └── types/            ← api.ts (TypeScript类型)
│   └── electron/             ← main.ts, preload.ts
├── backend/                  ← Spring Boot 2.7
│   └── src/main/java/com/dbdocai/
│       ├── config/           ← WebConfig, LlmConfig, LlmProperties
│       ├── controller/       ← DataSourceController, DocumentController, LlmController
│       ├── dto/              ← DataSourceConfigDTO
│       ├── llm/              ← LlmAdapter, 4种实现, LlmAdapterFactory, LlmException
│       ├── metadata/         ← MetadataCollector (JDBC元数据读取)
│       └── service/          ← DataSourceStoreService, DocumentService, LlmConfigService
└── docs/                     ← 开发计划文档
```
