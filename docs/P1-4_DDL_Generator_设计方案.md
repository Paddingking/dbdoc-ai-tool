# P1-4: DDL 一键生成 设计方案

## 1. 背景与目标

### 痛点
- 看文档知道字段定义了，但要建表还得手写 CREATE TABLE
- 迁移/同步/归档时经常需要复制 DDL
- 注释更新后需要同步到 DDL 里

### 目标
为任意表一键生成完整的 `CREATE TABLE` 语句（含 PRIMARY KEY、INDEX、COMMENT、外键），支持单表复制和批量导出。

## 2. DDL 生成范围

| 元素 | 包含 | 说明 |
|------|------|------|
| 表名 | ✅ | 原始表名 |
| 字段定义 | ✅ | 字段名 + 类型 + 长度/精度 + NOT NULL + DEFAULT + COMMENT |
| 主键 | ✅ | `PRIMARY KEY (col1, col2)` |
| 索引 | ✅ | `CREATE INDEX idx_name ON table(col); CREATE UNIQUE INDEX...` |
| 外键 | ✅ | `CONSTRAINT fk_name FOREIGN KEY (col) REFERENCES parent(col)` |
| AUTO_INCREMENT | ✅ | MySQL: `AUTO_INCREMENT`，PG: `SERIAL` / `GENERATED BY DEFAULT AS IDENTITY` |
| 表注释 | ✅ | `COMMENT ON TABLE name IS '...'` |
| 枚举值 | ⬜ | 注释提示（非 DDL 元素） |

## 3. DDL 生成算法

### 3.1 核心逻辑

```java
public String generateCreateTable(TableInfo table, String dbType) {
    StringBuilder sb = new StringBuilder();
    sb.append("CREATE TABLE ").append(quoteName(table.name, dbType)).append(" (\n");

    // 1. 字段定义
    List<String> colDefs = new ArrayList<>();
    for (ColumnInfo col : table.columns) {
        colDefs.add(buildColumnDef(col, dbType));
    }
    sb.append("  ").append(String.join(",\n  ", colDefs));

    // 2. 主键约束
    List<String> pkCols = table.columns.stream()
        .filter(c -> c.primaryKey).map(c -> c.name).collect(toList());
    if (!pkCols.isEmpty()) {
        sb.append(",\n  PRIMARY KEY (")
            .append(pkCols.stream().map(n -> quoteName(n, dbType)).collect(joining(", ")))
            .append(")");
    }

    sb.append("\n)");

    // 3. 表选项（引擎等）
    if ("mysql".equals(dbType) && table.engine != null) {
        sb.append(" ENGINE=").append(table.engine).append(" DEFAULT CHARSET=utf8mb4");
    }

    sb.append(";\n");

    // 4. 表注释
    if (table.comment != null && !table.comment.isEmpty()) {
        sb.append(generateTableComment(table, dbType));
    }

    // 5. 索引
    for (Map<String, String> idx : table.indexes) {
        sb.append(generateIndexSQL(table.name, idx, dbType));
    }

    // 6. 外键（ALTER TABLE）
    for (Map<String, String> fk : table.foreignKeys) {
        sb.append(generateForeignKeySQL(table.name, fk, dbType));
    }

    return sb.toString();
}
```

### 3.2 字段类型转换

不同数据库对同一 JDBC type 的表示可能不同。数据结构中存储的是 JDBC 原生类型名，直接使用即可：

```java
private String buildColumnDef(ColumnInfo col, String dbType) {
    StringBuilder def = new StringBuilder();
    def.append("  ").append(quoteName(col.name, dbType)).append(" ");
    def.append(mapDataType(col.dataType, col.columnSize, col.decimalDigits, dbType));

    if (!col.nullable) def.append(" NOT NULL");
    if (col.defaultValue != null && !col.defaultValue.isEmpty()) {
        def.append(" DEFAULT ").append(col.defaultValue);
    }
    if (col.autoIncrement && "mysql".equals(dbType)) {
        def.append(" AUTO_INCREMENT");
    }

    return def.toString();
}
```

### 3.4 注释语法差异

```sql
-- MySQL
COMMENT ON TABLE order_main IS '订单主表';
COMMENT ON COLUMN order_main.id IS '主键ID';

-- PostgreSQL / DM / Kingbase8 / Oracle
COMMENT ON TABLE order_main IS '订单主表';
COMMENT ON COLUMN order_main.id IS '主键ID';
-- (语法相同)
```

## 4. 后端设计

### 4.1 DdlService

```java
@Service
public class DdlService {

    public String generateTableDdl(String dataSourceId, String schema, String tableName) {
        DataSourceConfigDTO ds = storeService.get(dataSourceId);
        try (Connection conn = createConnection(ds)) {
            TableInfo table = collector.collectTable(conn, catalog, schema, tableName, false);
            return buildCreateTable(table, ds.getDbType());
        }
    }

    public String generateMultipleDdl(String dataSourceId, String schema, List<String> tableNames) {
        StringBuilder all = new StringBuilder();
        for (String tn : tableNames) {
            all.append(generateTableDdl(dataSourceId, schema, tn)).append("\n\n");
        }
        return all.toString();
    }
}
```

## 6. 边界与限制

| 场景 | 处理 |
|------|------|
| 表无主键 | 正常生成，不含 PRIMARY KEY 约束 |
| JSON/XML 类型 | 使用原始类型名 |
| Oracle 特有类型（CLOB/BLOB） | 使用原始类型名 |
| MySQL AUTO_INCREMENT 字段不是主键 | 不生成 AUTO_INCREMENT（需唯一键） |
| 达梦 DM 的 IDENTITY 字段 | 保持原始类型，不转换 |
